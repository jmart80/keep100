# Keep100 in the browser (claude.ai)

Use this if you can't use the Claude desktop app. Every Keep100 skill works in the browser. Two things are different: Claude can't keep a folder on your computer up to date, so your company files live in a Claude Project that you update by hand, and the weekly brief can't run against your files on a schedule. You still need a paid Claude plan.

## 1. Install the plugin

1. At claude.ai, open **Customize**, then **Plugins**.
2. Add the marketplace `jmart80/keep100` and install **Keep100**.

The plugin is attached to your account, so its skills are there in every chat, and in the desktop and mobile apps too.

If you don't see Plugins under Customize, your plan or your organization may not allow adding them. The desktop app won't change that. Ask whoever manages your Claude account.

## 2. Create a Keep100 project

1. In claude.ai, create a Project called **Keep100**.
2. Start a chat in it and say: **"Set me up with Keep100. I'm in the browser."**
3. Claude will run setup in the chat and give you each company file, your progress file and the house rules as text to save.
4. Add the company files and `progress.md` to the project's knowledge, and paste the house rules into the project's instructions.

## 3. Keep one version of the truth

This is the part that needs care in the browser. Your files live in the project knowledge, not on your computer, so:

- **When something changes** (a price, a feature, your ideal customer, a step finished), ask Claude for the updated file and replace the old one in project knowledge right away.
- **Keep one project if you can.** If you split work into several projects (say, one for social and one for sales), every project needs the same company files, and every change has to be made in each one. That's how Claude ends up quoting an old price.
- **Claude's memory is not a company file.** If Claude remembers a price from an old chat and it differs from `pricing.md`, the file wins. Tell Claude so if it happens.

## 4. Each day

Open a chat in the Keep100 project and ask **"what's today?"** Paste in what you did since last time (who you emailed, what you posted). When a step is done, Claude gives you the updated `progress.md` to save over the old one.

## 5. Your dashboard

Ask **"show me my dashboard"**. Claude builds the page from your `progress.md` and shows it in the chat. It reflects your progress as of that chat, so ask again whenever you want a fresh one.

## 6. Weekly brief

Set a reminder for Monday morning to open the project and ask for your weekly brief.
