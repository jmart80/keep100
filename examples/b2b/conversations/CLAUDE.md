# Conversation rules

- One file per conversation: `<date>-<first-name>-<role>.md`.
- First name, role and type of company are enough. Note whether they agreed to be recorded.
- A quote is `[verbatim]` only when it comes from a transcript or something the person wrote. Notes from memory are `[paraphrase]`.
- Never store anything about a person's health, money trouble or other sensitive matters.
- Findings move into `company/customers.md` only after three conversations agree, and only with the founder's yes.
- Delete a person's file if they ask.
