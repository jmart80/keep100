# Listing kit

Fill every field from the company files. Confirmed facts only. Leave a field out if nothing confirmed fits it.

```
# Listing kit: {product}
Last updated: {date}

## Name
{Exact spelling from company/brand.md}

## One line (under 60 characters)
{What it is, for whom. The category word a customer would search for must be in it.}

## Short description (under 160 characters)
{The landing page hero, compressed.}

## Medium description (about 50 words)
{What it is, who it is for, what it replaces, the one thing only it does.}

## Long description (about 150 words)
{Problem in the customer's words. What the product does about it. Three capabilities, each with its outcome. What is live today. Price and the founding offer, if open.}

## Founder's note (about 80 words, first person)
{Why the founder built it. One true, specific moment. What they want from readers: feedback, first customers, or both.}

## Categories and tags
{Five, in the customer's vocabulary.}

## Links
- Website: {URL}
- Signup or checkout: {URL from company/product.md}
- Tagged link pattern: {URL}?ref={place}

## Pricing line
{From company/pricing.md, word for word.}

## Images to prepare
1. {The screen that shows the main capability, with real or realistic data}
2. {The before and after, if the product replaces a manual step}
3. {The result the customer ends up with}
Logo: {square, and wide}

## Questions people will ask, with answers
1. {Top hesitation from company/customers.md} : {answer from confirmed facts}
2. {How is it different from the main alternative} : {from company/positioning.md}
3. {Price and what happens after the trial} : {from company/pricing.md}
4. {Is my data safe} : {only if confirmed, otherwise leave out}
5. {Who is behind it} : {the founder, one line}
```

## Checks

- The category word appears in the one-liner
- No superlatives, no "the best", no invented numbers
- The same price and the same offer wording as `company/pricing.md`
- A stranger who reads only the medium description can say what it is and who it is for
