# Marketing rules

- Read `company/positioning.md` and `company/brand.md` before writing anything here.
- If positioning is still Draft, say so and suggest running positioning first, but help anyway if the founder wants to proceed.
- Pages and emails use only claims from Confirmed company files or `[confirmed]` facts. No invented numbers, testimonials, ratings or logos.
- Every button and link points at the address in `company/product.md`. If none is recorded, ask.
- Run `keep100:writing-check` before showing a draft.
