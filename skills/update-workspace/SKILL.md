# Update workspace

The founder's workspace belongs to them. Updates never change it without a yes.

## Steps

1. Read `Kit version:` in `progress.md` and this plugin's version in `plugin.json`.
2. Read [changes.md](changes.md) for every version between the two.
3. Explain each change in one plain sentence ("There's now a place for customer testimonials"). Ask yes or no for each.
4. Apply only the approved changes. Never edit, reorder or reformat the founder's own content while doing it.
5. Set `Kit version:` in `progress.md` and the version line at the bottom of `CLAUDE.md` to the new version, and note declined changes at the bottom of `progress.md` so you don't ask again.

Skills must keep working if a founder declined an optional change.
