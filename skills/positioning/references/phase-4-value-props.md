# Phase 4 Reference: Value Prop Extraction

Everything here is translation, not invention. The inputs already exist: struggling moments from Phase 1, unique attributes from Phase 2, the champion from Phase 3.

## The pain, capability, outcome map (Lerner, Fletch, converged across all practitioners)

Every framework in this skill converges on the same three-tier translation:

| Research input | Messaging layer | Copy application |
|---|---|---|
| Struggling moment (JTBD) | Pain, the before state | Hero headline, problem section |
| Competitive alternative gaps (Dunford) | Capability, what the product can do | H2 subhead, capability sections |
| Desired outcome (JTBD pull, Bourgoin selfish desire) | Outcome, the after state | Value proposition, CTA |

**Build the map:** for each top-ranked struggling moment from Phase 1, pair it with the unique attribute from the Phase 2 canvas that resolves it and the outcome the buyer described wanting. Discard any pain the product cannot uniquely resolve; those belong to the category, not to this product.

**Value prop statement form:** one pain plus one capability plus one outcome, written in the buyer's vocabulary. Produce 3 to 5. Each must trace to at least one verbatim and one canvas attribute; a value prop with no verbatim behind it is invented copy and gets cut.

## Language/market fit (Matt Lerner, First Round Review)

Language/market fit is when the words explaining the product make prospects feel their minds were read. Without it, landing page conversion sits around 0.5 to 3%; with it, 8 to 40%. Finding the words is step zero, before any creative copywriting.

**The 4-step process:**

1. Return to the JTBD interviews: what was in buyers' heads before they found a solution, and what exact words described the struggle?
2. Draft headlines and subheads using that exact language, never internal vocabulary or feature names.
3. Test qualitatively: comprehension tests and five-second tests. Keep only headlines where ICP respondents immediately understand what the product does and why it matters.
4. Test quantitatively: run 4 identical ad creatives with 4 different headlines against a real ICP audience. Faster and cheaper than landing page A/B tests, and needs less traffic.

**Output for the packet:** 10 to 20 headline candidates, each tagged with the verbatim that sourced it. Steps 3 and 4 become the Phase 5 validation plan when the user has budget and audience access; otherwise deliver the candidates ranked by verbatim frequency and intensity.
